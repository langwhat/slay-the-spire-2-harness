# Bind context lifetime to its agent

Context is an exclusively owned internal component of its Agent, with no independent task or lifecycle: Run retains it throughout one native act and is replaced on a confirmed native act transition, while Combat retains it through review and result handoff for one nonterminal battle. Boss reward completion is not a lifecycle trigger. A confirmed terminal result ends the run without a review or further model calls; releasing each agent ends active ownership of its Context and delivery ledger, while RunSession retains strategy notes and orchestration retains nonterminal handoff values independently. This makes Run Agent act-scoped instead of replacing contexts inside a run-scoped agent, while ordinary node and phase changes preserve the living agent's conversation and archived evidence remains available.
