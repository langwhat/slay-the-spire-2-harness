# Deck plan

Keep the deck's plan in the strategy notes. `plan` states in a few lines the group of owned cards and relics the deck is built around, the rule or link that connects them, what the group still lacks, and which owned cards it does not use. In Act 1, before such a group exists, `plan` lists what the act's Elites and Boss still demand of the deck. Rewrite `plan` when the deck changes or a battle report contradicts it. Combat reads it at the start of each battle.

Supplied knowledge may list cores known for this character. When owned cards match one, build it. A group that is not listed can still be real when the rules and links support it.
